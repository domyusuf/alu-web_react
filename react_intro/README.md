# React Intro

> Introduction to the React Framework

This project introduces the fundamentals of building single-page applications using React. We start by exploring `create-react-app`, setting up basic components, styling with CSS, and modifying the default boilerplate to create a structured school dashboard.

## Task Overview

- **`task_0`**: Initializes the React app using `create-react-app`, implements a simple layout (Header, Body, Footer) using JSX, and imports static assets like the Holberton logo and custom favicons.
