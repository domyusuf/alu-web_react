# React Props

This project covers the fundamentals of React properties (props). It explores how to create reusable React components, pass data between them, define expected types using PropTypes, and optimize rendering loops with keys.

## Learning Objectives

- How to create basic React components using functions
- How to reuse components
- How to pass properties to components
- How to define types for components
- How to use Fragments
- When to use a key to improve a loop's performance

## Requirements

- Environment: Ubuntu 18.04 LTS
- Node: 12.x.x
- npm: 6.x.x
- Editors: vi, vim, emacs, Visual Studio Code
- All files end with a new line
- Mandatory README.md at the project root
