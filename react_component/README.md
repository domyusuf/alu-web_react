# React Component

This project explores the depths of React components, focusing on when to use Class vs Functional components, component lifecycle methods, testing with Enzyme, using Jest spies, implementing Higher Order Components (HOCs), and optimizing rendering performance with Pure components.

## Learning Objectives

- When to use a Class or a function to create a component
- The lifecycle of a Class component
- How to test a component
- How to utilize a Jest spy to verify that a function is being called correctly
- What an HOC is and how to use it
- How to optimize performance and control which components to render

## Requirements

- Environment: Ubuntu 18.04 LTS
- Node: 12.x.x
- npm: 6.x.x
- Editors: vi, vim, emacs, Visual Studio Code
- All files end with a new line
- Mandatory README.md at the project root
